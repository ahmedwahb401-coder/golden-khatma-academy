# أكاديمية الختمة الذهبية

موقع أكاديمية تحفيظ قرآن أونلاين، مبني بـ Next.js 15 (App Router) و TypeScript و
Tailwind CSS، ومتصل بقاعدة بيانات Supabase.

## الحالة الحالية للمشروع

هذا **أساس حقيقي وشغّال** للمشروع (وليس نموذجاً تجريبياً) — الهيكل، الهوية البصرية،
الصفحة الرئيسية، صفحتا الرجال والنساء، نموذج التسجيل المربوط فعلياً بـ Supabase،
ونظام تسجيل الدخول الكامل (Supabase Auth)، كلها جاهزة وشغّالة. الأجزاء التالية لم
تُبنَ بعد وتحتاج جلسات لاحقة لإكمالها:

- تقرير PDF منسّق بالكامل بالعربي (الحالي نصي بالإنجليزية داخل الملف لتفادي مشاكل
  عرض الخط العربي في jsPDF من المتصفح — للعربي الكامل يُفضّل توليد PDF من
  السيرفر بمكتبة تدعم تضمين خط عربي مثل Amiri).
- ربط فعلي بخدمات واتساب/إيميل خارجية (التسجيل في قاعدة البيانات جاهز، الإرسال الحقيقي لا).
- الأيقونات الحالية مولّدة برمجياً (علامة ربع الحزب بسيطة) — استبدلها بشعار
  نهائي احترافي عند توفره.

### الصفحات الثابتة (جديد)

- **`/about`** — من نحن: تعريف، رؤية، رسالة، أهداف.
- **`/teachers`** و **`/teachers/women`** — عرض عام للمحفّظين والمحفّظات (بيانات حية من Supabase).
- **`/contact`** — واتساب، هاتف، إيميل، خريطة Google Maps (استبدل الرابط بموقعك
  الفعلي)، ونموذج مراسلة يخزّن الرسائل في جدول `contact_messages` (يظهر للأدمن فقط).

### التقارير والإشعارات (جديد)

- **`/admin/reports`** — يولّد تقرير PDF فوري لأي طالب (نسبة الحضور، آخر جلسات
  التسميع والدرجات، سجل المدفوعات) مباشرة في المتصفح باستخدام مكتبة `jspdf`
  (لا يحتاج سيرفر إضافي)، ويسجّل كل تقرير في جدول `reports`.
- **`/admin/notifications`** — يرسل (يسجّل) إشعاراً لأي طالب عبر واتساب أو
  إيميل، يظهر فوراً في لوحة الطالب. **الإرسال الفعلي** عبر واتساب/إيميل حالياً
  غير مفعّل — الدالة `sendNotification` في `app/admin/notifications/actions.ts`
  هي نقطة الربط الجاهزة؛ لتفعيل الإرسال الحقيقي أضف فيها استدعاءً لخدمة مثل
  Twilio (واتساب) أو Resend (إيميل).

### SEO و PWA أساسية (مكتملة الآن)

- `app/sitemap.ts` و `app/robots.ts` يولّدان `/sitemap.xml` و `/robots.txt`
  تلقائياً (عدّل `BASE_URL` في كليهما وفي `app/layout.tsx` بنطاقك الفعلي بعد النشر).
- Metadata كاملة لكل صفحة عامة (عنوان، وصف، Open Graph، Twitter Card)، بالإضافة
  لـ `title.template` مركزي في `app/layout.tsx` بحيث أي صفحة جديدة تاخد صيغة
  العنوان الموحّدة تلقائياً.
- بيانات منظّمة (JSON-LD / Schema.org، نوع EducationalOrganization) مضافة في
  `<head>` لتحسين ظهور الموقع في نتائج البحث.
- صفحات لوحتي الإدارة والتحكم (`/admin`, `/dashboard`) عليها `robots: noindex`
  بالإضافة لمنعها في `robots.txt`.
- أيقونات حقيقية جاهزة (`public/icon-192.png`, `public/icon-512.png`,
  `public/apple-touch-icon.png`, `app/favicon.ico`) وصورة مشاركة اجتماعية
  (`app/opengraph-image.png`) — كلها مولّدة بهوية الأكاديمية (أخضر + ذهبي +
  علامة ربع الحزب)، جاهزة للاستخدام أو الاستبدال بشعار نهائي لاحقاً.
- دعم PWA أساسي فعّال: `public/manifest.json` مكتمل بالأيقونات الحقيقية، مع
  Service Worker بسيط (`public/sw.js`) يخزّن الصفحات الرئيسية للعمل بدون
  إنترنت (استراتيجية "الشبكة أولاً" مع الرجوع للكاش)، ويُسجَّل تلقائياً في
  بيئة الإنتاج فقط عبر `components/ServiceWorkerRegister.tsx`.

### لوحتا الطالب والمحفّظ (جديد)

- **`/dashboard/student`** — يعرض خطة الطالب، بيانات المحفّظ، آخر الحضور، سجل
  التسميع والدرجات، الإشعارات، وأداة لرفع واجب صوتي.
- **`/dashboard/teacher`** — يعرض قائمة طلاب المحفّظ، ولكل طالب نموذج لتسجيل
  حضور وتسميع ودرجة وملاحظات جلسة اليوم بضغطة واحدة.
- **مهم:** الربط بين حساب الدخول وسجل الطالب/المحفّظ يتم عبر عمود `user_id` في
  جدولي `students` و`teachers`. الآن يمكن عمل هذا الربط مباشرة من لوحة الإدارة:
  في تبويبي "الطلاب" و"المحفّظون" ستجد عمود/قائمة "اربط بحساب" تسمح باختيار أي
  حساب دخول (لسه مربوط) وربطه بسجل الطالب أو المحفّظ المناسب.
- **لتفعيل رفع الواجبات الصوتية:** من Supabase Dashboard اذهب لـ Storage، وأنشئ
  bucket جديد باسم `homework` (يفضّل جعله Public لتسهيل تشغيل الصوت مباشرة).

- `/login` — صفحة دخول موحّدة للإدارة والمحفّظين والطلاب (Supabase Auth بالبريد وكلمة المرور).
- `/dashboard` — مسار محمي، يعيد التوجيه لـ `/login` تلقائياً لو المستخدم غير مسجّل دخوله
  (عبر `middleware.ts`)، ويعرض بطاقة ترحيب مختلفة حسب الدور (admin/teacher/student).
- عند إنشاء أي مستخدم جديد في Supabase Auth، يُنشأ له تلقائياً سجل في `public.users`
  بدور "student" افتراضياً (عبر trigger في `schema.sql`). لترقية مستخدم لـ admin أو
  teacher، عدّل عمود `role` يدوياً من Table Editor في البداية، وحتى تُبنى شاشة إدارة
  المستخدمين.

قاعدة البيانات كاملة الجداول (`lib/supabase/schema.sql`) جاهزة لتغطية كل ما سبق،
فالخطوة القادمة غالباً هي بناء الواجهات فوقها.

## هيكل المشروع

```
app/
  layout.tsx          Layout عام (RTL + SEO metadata)
  page.tsx             الصفحة الرئيسية
  men/page.tsx          قسم الرجال
  women/page.tsx        قسم النساء
  register/page.tsx     صفحة التسجيل
components/            كل مكونات الواجهة (Hero, Programs, Navbar...)
lib/
  data.ts              بيانات نموذجية (برامج، محفّظون، إلخ) — استبدلها لاحقاً باستعلامات Supabase
  schemas.ts           Zod schema للتحقق من نموذج التسجيل
  supabase/
    client.ts           عميل Supabase للمتصفح
    server.ts           عميل Supabase للسيرفر
    schema.sql           كل جداول قاعدة البيانات
```

## التشغيل محلياً

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **إعداد Supabase:**
   - أنشئ مشروعاً جديداً على [supabase.com](https://supabase.com).
   - من `SQL Editor`، نفّذ محتوى الملف `lib/supabase/schema.sql` لإنشاء الجداول.
   - من `Project Settings > API`، انسخ `Project URL` و `anon public key`.
   - انسخ `.env.local.example` باسم `.env.local` وضع فيه القيمتين.

3. **تشغيل السيرفر المحلي:**
   ```bash
   npm run dev
   ```
   الموقع هيشتغل على `http://localhost:3000`.

## النشر على Vercel

1. ارفع المشروع على GitHub (repository جديد).
2. من [vercel.com](https://vercel.com) اختر "Add New Project" واربط الـ repository.
3. في إعدادات المشروع على Vercel، أضف Environment Variables:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   (بنفس القيم الموجودة في `.env.local`)
4. اضغط Deploy — Vercel هيتكفل بالبناء والنشر تلقائياً مع كل push جديد.

## ملاحظات على الهوية البصرية

الألوان والخطوط معرّفة مركزياً في `tailwind.config.ts`:
- `primary` (أخضر زمردي `#0F6B4B`) و`secondary` (ذهبي `#D4AF37`).
- خط `font-display` (Amiri) للعناوين، و`font-body` (Tajawal) للنصوص.
- العنصر البصري المميز للموقع هو علامة **"ربع الحزب"** الهندسية
  (`components/RubElHizb.tsx`) — نفس العلامة المستخدمة في المصحف لتمييز
  الأجزاء والختمات، تظهر بشكل هادئ في الخلفيات والشعار والفواصل.

## الخطوة التالية المقترحة

الأنسب هو استكمال المشروع تدريجياً: صفحة واحدة أو ميزة واحدة في كل مرة (مثلاً
لوحة تحكم الإدارة بجدول الطلاب فقط أولاً)، بدل محاولة بناء كل شيء دفعة واحدة —
هذا يحافظ على جودة الكود وسهولة المراجعة.
